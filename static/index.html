HOW IT WORKS

Reason, act, respond.

01

Pick an engine

Choose Groq, Gemini, or any model behind OpenRouter — swap providers mid-conversation without losing context.

02

Agent reasons

A LangGraph ReAct loop decides whether it needs to search the live web via Tavily before answering.

03

Streams back

Tokens arrive live over SSE, rendered as markdown with syntax-highlighted, copyable code blocks.

CAPABILITIES

Built for real conversations, not demos.

◆

Real memory

Full chat history is sent to the agent every turn — it remembers what you said three messages ago.

▤

Persistent sessions

Every conversation is saved server-side in SQLite. Close the tab, come back tomorrow — it's still there.

◐

Live web search

Toggle Tavily search on for any message when the model needs current information.

▍

Token streaming

No spinners — answers appear word by word as the model generates them.

◈

Custom personas

Set a system prompt per session to reshape how the agent behaves, no code changes needed.

⌘

Markdown & code

Responses render as proper markdown with syntax-highlighted code blocks and one-click copy.
